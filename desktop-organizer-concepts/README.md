# 桌面待办、倒计时与文件收纳：三窗口原型

打开 `index.html` 即可查看可交互原型。待办、倒计时和文件收纳是三个可独立拖动的小窗口。

可体验的交互：

- 拖动每个窗口的标题栏，分别调整桌面位置。
- 图钉按钮用于置顶或取消置顶；菜单支持紧凑模式、最小化和恢复初始位置。
- 点击待办完成框，查看盖章、粒子反馈、列表退出和撤销提示。
- 待办摘要分别显示“今日完成”和“总共完成”；完成或撤销任务时两个指标同步更新。
- 倒计时窗口支持新增名称、截止日期时间和紧急预警阈值。
- 正常倒计时保持黑色；进入预警范围后对应条目会抖动；超时后变为红色并触发爆炸粒子、警告闪烁和冲击阴影。
- 用户新增的倒计时会保存在本地，重新打开原型仍然保留。
- 点击“新待办”进入带切换动画的任务设置流程。
- 新待办支持开始日期、结束日期、不重复、每天、工作日、每周、每月和每年。
- 每周任务可以选择具体星期，且可以单独开启提醒时间。
- 每一条现有待办右侧都有编辑按钮，可重新修改名称、日期、周期、星期与提醒；保存修改不会重复增加任务。
- 新增及修改后的待办数据会保存在本地。
- 新增任务后进度总数会同步更新。
- 点击或拖入文件，将项目加入快捷收纳盒。

旧版樱花背景概念保存在 `archive/index-v1.html`，当前版本不再使用图片背景。
